# nginx TLS for plistCSV (port **58787**)

Public URL pattern matches other apps on this host (e.g. fraBering **58785** → app **58779**).

| Role | Port |
|------|------|
| nginx `listen 58787 ssl` | HTTPS (`https://smircich.ddns.net:58787`) |
| Express (`server/config/environment/index.js`) | **58788** on `127.0.0.1` |

Block in `/etc/nginx/sites-available/default` (sites-enabled symlink).

**59010** is reserved for another host on the LAN — do not use it for plistCSV.

## After editing nginx or app port

```bash
sudo nginx -t && sudo systemctl reload nginx
```

Restart the app (`grunt serve` / screen session) so Node binds **58788**.

## Local checks

```bash
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:58788/    # app direct (HTTP)
curl -sk -o /dev/null -w "%{http_code}\n" https://127.0.0.1:58787/ # via nginx (HTTPS)
```

## Router (WAN)

Forward **WAN TCP 58787** → **192.168.1.120:58787** (same pattern as 59090 / 58785). Test from cellular after adding the rule; LAN hairpin to the public DDNS often fails even when forwarding is correct.
